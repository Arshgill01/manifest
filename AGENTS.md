# AGENTS.md: the Bot fleet

Manifest v2 is meant to be worked on by five Bots, each owning one lane. Every Bot reads `CLAUDE.md`,
`SPEC.md` (v2) and `CONTRACT.md` first; everything in `CLAUDE.md` applies to Bots too. This file adds the
rules that let five of them work at once without trampling each other or the evidence.

## Invariants

1. **One ticket, one Bot, one branch.** Work happens on `bot/<lane>/<ticket>` (e.g. `bot/bug-smith/LIN-20`),
   merged through a PR. Never push to `main`; never use a `devin/*` branch (CI rejects it).
2. **Stay in your lane.** `.github/workflows/bot-lane-guard.yml` fails any PR whose branch lane touches a
   path outside that lane (table below), and any PR from `bot/referee/*` that changes files.
3. **No Bot touches the evaluation core**: `SPEC.md`, `CONTRACT.md`, `CLAUDE.md`, `AGENTS.md`, `growth/`,
   `harness/`, `tasks/splits.json`, `pyproject.toml`, `uv.lock`, or `.github/` (except `skills.yml` for
   Registry Keeper). What defines, runs and scores an experiment changes only by a human.
4. **Numbers come from logs.** `RESULTS.md` is regenerated by `growth/results.py` from committed
   `.manifest/runs/*.jsonl`; never hand-edited.
5. **Cache first, one model at a time.** Model-backed jobs go through `.manifest/queue.txt` and
   `scripts/queue.sh`, one at a time. Before queueing, check `.manifest/cache/` and
   `.manifest/growth/*/checkpoint.json`: a cached task is never re-run, a growth run is resumed, not
   restarted. Never pass `--force` without a ticket that says why.
6. **Grown code is never hand-written.** `harnesses/*/routines/`, `routines/grown/` and grown skills come
   only from growth runs (`growth.stream`) and `growth.promote`, with provenance in a log.

## Lanes

| Lane | Branch | May change | Job |
|---|---|---|---|
| Lab Runner | `bot/lab-runner/*` | `.manifest/{runs,cache,growth}/`, `.manifest/queue.txt`, `.manifest/teacher-ledger.jsonl`, `harnesses/`, `experiments.json`, `RESULTS.md` | Works through the E1–E8 queue, commits logs, regenerates results |
| Bug Smith | `bot/bug-smith/*` | `tasks/` (not `splits.json`), `tests/test_tasks_*.py` | Grows the verified bug suite, append-only |
| Red Team | `bot/red-team/*` | `warden/`, `skills/warden/`, `demo/{thirdparty-skills,fakehome}/`, `demo/sink.py`, `tests/test_warden_*.py` | Writes hostile skills; every escape becomes a Warden fix plus a regression test |
| Registry Keeper | `bot/registry-keeper/*` | `skills/`, `.github/workflows/skills.yml` | Exports grown routines as Agent Skills and keeps them valid |
| Referee | `bot/referee/*` | nothing | Reviews every PR for held-out leakage, special-casing, self-grading and `CONTRACT.md` drift |

Anything a lane needs outside its paths becomes a ticket for the lane that owns it, or for the maintainer.
Check the guard locally: `git diff --name-only --no-renames main... | bash .github/scripts/lane-guard.sh <branch>`.
